# Tero

**Plataforma abierta de inspecciones municipales.**
*El tero avisa.*

Tero digitaliza el ciclo completo de una inspección municipal: el objeto del
territorio, la recorrida, el acta con su plazo, la reinspección y los
indicadores. Funciona desde el navegador del celular, también sin señal.

Propuesta de piloto de código abierto para el programa
**GovTech Connect · CIIAR Uruguay** (BID Lab + Red de Innovación Local).
