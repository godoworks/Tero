# Política de seguridad

Tero está pensado para operar dentro de gobiernos locales, con datos de personas,
comercios y actuaciones administrativas. Una vulnerabilidad acá no es un detalle
técnico: puede exponer información de vecinos o invalidar un acta.

## Cómo reportar

**No abras un issue público.** Hay dos canales privados:

- Reporte privado de GitHub: repositorio → pestaña **Security** → **Report a vulnerability**
- Correo: **info@godoworks.com**

Contanos qué encontraste, cómo reproducirlo y, si podés, qué impacto le ves.

## Qué esperar

| Momento | Compromiso |
|---|---|
| Dentro de 3 días hábiles | Acusamos recibo del reporte |
| Dentro de 10 días hábiles | Te decimos si lo confirmamos y cómo pensamos resolverlo |
| Al publicar el arreglo | Te damos crédito, salvo que prefieras lo contrario |

Pedimos no divulgar públicamente el problema hasta que haya una versión corregida
disponible, para no dejar expuestas a las intendencias que ya lo estén usando.

## Alcance

Entra en alcance el código de este repositorio. No entran las instalaciones
particulares de cada gobierno local ni la infraestructura donde las alojan: si
encontrás un problema en una instalación concreta, avisale a esa intendencia.
